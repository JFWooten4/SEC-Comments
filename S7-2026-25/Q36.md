# Question 36 — reuse of an electronic address within the same transfer agent

_Source: SEC, [Electronic Delivery of Information Under the Federal Securities Laws, Release No. 33-11430; File No. S7-2026-25](https://www.sec.gov/files/rules/proposed/2026/33-11430.pdf#page=65), Question 36 at printed pp. 65–66; see also the discussion and footnote 118 at [printed p. 63](https://www.sec.gov/files/rules/proposed/2026/33-11430.pdf#page=63)._

## Draft argument

Question 36 should be answered yes in the narrower circumstance where a shareholder's electronic address remains within the same transfer agent's recordkeeping and delivery system. The Commission should permit that transfer agent to use an address already associated with the same verified shareholder when acting for another issuer whose securityholder records the same transfer agent maintains, without requiring the shareholder to re-enter the identical address issuer by issuer.

The important distinction is that the address does not move from Issuer A to Issuer B, or from one service provider to another. It stays with the same transfer agent. For example, a shareholder may provide an email address to Issuer A, which supplies the address to its transfer agent as part of the shareholder record, or the shareholder may provide the address directly through the transfer agent's portal while interacting with Issuer A's records. If that same transfer agent later maintains a verified record for the same shareholder in Issuer B, the transfer agent should be able to use the address already on file to deliver covered information on behalf of Issuer B.

This circumstance is distinct from unrestricted portability of an address among covered entities or third parties. The proposal states that a covered entity remains ultimately responsible for compliance when it uses an agent or other third party to deliver information on its behalf. The requested treatment would not alter that responsibility. Each issuer or other person with the underlying delivery obligation would remain responsible for compliance; the transfer agent would simply avoid forcing the same shareholder to provide the same contact field again when the address never left the agent's system.

The proposal already recognizes that an email address supplied during onboarding ordinarily may indicate an expectation that the recipient will receive communications about a variety of matters. Footnote 118, however, generally treats an address received from another person as insufficient for commencing e-delivery. Applied mechanically to a common transfer-agent system, that approach can make the result depend on which issuer record first supplied an address that the transfer agent already maintains for the same verified person.

The Commission's concern that recipients understand how an electronic address will be used can be addressed at the point of first use for an additional issuer. The transfer agent can provide the disclosure required by proposed § 303.102(b), identify the covered entity on whose behalf the delivery is being made, explain that the address is already on file with the transfer agent, describe the categories of covered information that may be sent, and provide a simple means to update the address or opt out. The rule should also permit a shareholder to make a transfer-agent-level election such as: “Use this email address for required shareholder communications from any issuer for which this transfer agent maintains my account or position.”

The address should remain under the transfer agent's control for this purpose. Issuer B need not receive the address merely because the transfer agent uses it to perform delivery on Issuer B's behalf, and Issuer B need not learn anything about the shareholder's relationship with Issuer A. Keeping the address inside one common recordkeeping system can therefore avoid unnecessary duplication and unnecessary transfers of contact data between issuers.

This treatment should apply only when the transfer agent can reasonably verify that the records concern the same covered recipient and the address was obtained in circumstances reasonably indicating that it may be used for shareholder, account, or regulatory communications. It should not convert an address supplied solely for an unrelated purpose, such as technical support, into a regulatory-delivery address. Nor should it override the existing purpose limitation in 17 CFR 240.14a-16(k)(2) for an email address obtained solely to fulfill a request for a copy of proxy materials. Permission to use an address for covered information likewise should not itself constitute permission to send marketing or other non-covered communications.

At minimum, a same-transfer-agent safe harbor should require reliable identity matching; first-use disclosure that identifies the additional covered entity; issuer-specific and transfer-agent-wide opt-out or update controls; no disclosure of one issuer relationship to another issuer merely because the agent uses the common address; preservation of any purpose-specific legal restriction on the address; and ordinary bounce-back and remediation procedures.

A rule along these lines would preserve the proposal's notice and recipient-control objectives while recognizing that a transfer agent may maintain one shareholder identity across records for many issuers. The relevant question in this circumstance should be whether the same transfer agent already holds an address that the same verified shareholder provided or accepted for shareholder or regulatory communications, and whether the shareholder is told and can control how that address is used—not whether the shareholder manually re-enters the same address once for each issuer serviced by that transfer agent.

## Possible rule concept

When a transfer agent maintains records for a covered recipient with respect to more than one covered entity, an electronic address already maintained by that transfer agent for the same covered recipient may be treated as provided or accepted for use for covered information on behalf of an additional covered entity, provided that: (1) the transfer agent reasonably verifies that the records concern the same covered recipient; (2) the address was obtained in circumstances reasonably indicating that it may be used for shareholder, account, or regulatory communications and is not subject to a contrary purpose limitation; (3) before or with the first electronic delivery on behalf of the additional covered entity, the covered recipient receives the disclosure required by § 303.102(b) identifying that covered entity; (4) the covered recipient may update the address or opt out on an issuer-specific or transfer-agent-wide basis; and (5) the address need not be disclosed by the transfer agent to another issuer merely because the transfer agent uses it to perform delivery on that issuer's behalf.
